# Curated portfolio assets

This directory intentionally contains only four small, version-controlled
visual artifacts. The ignored `data/raw/` and `data/processed/` directories are
not redistributed.

## Held-out caption inputs

The three `sample_*.png` files are `64×64` RGB crops copied from the processed
test split, with one example per SKU class:

- `sample_dove_body_serum.png` — class 0.
- `sample_dove_deodorant.png` — class 1.
- `sample_lifebuoy_handwash.png` — class 2.

They let portfolio visitors run the real caption checkpoint without providing
their own image. They are examples from the same three-class domain, not the
complete dataset and not the only images used for training.

The source export identifies the
[Stock Segmentation dataset on Roboflow](https://universe.roboflow.com/dfdfdfd-d1nyr/stock_segmentation-dzocz)
as CC BY 4.0.

## Evaluation artifact

`phase2_cfg_class_grid.png` is a fixed-seed classifier-free-guidance sanity
check generated by this repository. It compares three class conditions while
holding the stochastic path fixed.
