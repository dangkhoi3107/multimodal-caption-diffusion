# Notebooks

Notebooks are limited to inspection, visualization, and experiment analysis. Core parsing, preprocessing, model, training, sampling, and metric implementations must live under `src/` and be invoked from notebooks.

Planned notebooks may visualize:

- COCO annotations and processed crop contact sheets.
- Forward diffusion at selected timesteps.
- Fixed-seed reverse denoising trajectories.
- Class/prompt comparisons.
- Caption predictions and attention maps.
